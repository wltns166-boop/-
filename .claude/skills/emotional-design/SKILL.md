# Emotional-Design — 갈등·불편 상황 완화

## 4단계 응답 구조
1. **인정**: 상황과 불편을 구체적으로 인정 ("결제가 두 번 처리되어 불편을 드렸습니다")
2. **설명**: 짧고 사실대로, 책임 회피 없이
3. **해결**: 지금 할 수 있는 것 + 언제까지
4. **선택권**: 사용자가 고를 수 있는 다음 행동 (재시도, 상담 연결, 취소)

## 상황별 원칙
- **거절**: "안 됩니다"로 끝내지 말고 가능한 대안을 함께 제시.
- **오류**: 사용자를 탓하는 표현 금지("잘못 입력하셨습니다" → "입력 형식을 확인해 주세요: 예) 010-1234-5678").
- **지연**: 예상 시간과 진행 상황을 보여준다.
- **분노**: 반박하지 않고 사실 확인 → 해결 순서로.

## 점검
- 사과는 한 번만, 구체적으로.
- 약속할 수 없는 것을 약속하지 않는다.
