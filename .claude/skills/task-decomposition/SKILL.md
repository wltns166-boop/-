# Task-Decomposition — 목표를 에이전트 역할로 분해

## 분해 절차
1. **목표 정의**: 완료 조건을 한 문장으로 (측정 가능하게).
2. **하위 작업 나열**: 각 작업은 입력·출력·완료 조건을 가진다.
3. **의존성 표시**: 순서가 필요한 작업(A→B)과 병렬 가능한 작업을 구분한다.
4. **역할 배정**: 작업 성격별로 역할을 붙인다 (조사자, 작성자, 검토자, 실행자).
5. **검증 지점**: 각 단계 끝에 누가 무엇으로 검증하는지 정한다.

## 작업 카드 형식
```
[작업] 경쟁사 요금표 수집
- 담당: 조사 에이전트
- 입력: 경쟁사 목록 5곳
- 출력: 표 (회사/상품/월 보험료/출처 URL)
- 완료 조건: 5곳 모두 출처 포함
- 의존: 없음 (병렬 가능)
```

## 규칙
- 한 작업이 한 역할로 끝나지 않으면 더 쪼갠다.
- 에이전트에게 넘길 때는 그 작업에 필요한 맥락을 모두 적는다 (상대는 대화 내용을 모른다).
