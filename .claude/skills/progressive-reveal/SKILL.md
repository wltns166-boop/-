# Progressive-Reveal — 단계별 정보 공개

## 3단 구조
1. **요약(1–2문장)**: 결론 먼저. 대부분의 사용자는 여기서 멈춘다.
2. **핵심 근거(3–5개 항목)**: 결론을 뒷받침하는 사실, 필요한 경우 표/이미지 1개.
3. **상세(접기/더보기)**: 전체 데이터, 예외, 기술적 설명.

## 멀티모달 순서
- 텍스트 요약 → 시각 자료(차트/이미지) → 상세 표 → 원문 링크
- 시각 자료에는 반드시 한 줄 해설을 붙인다.

## 규칙
- 한 단계에 새 개념은 3개 이하.
- 사용자가 "자세히"를 요청하면 다음 단계만 공개하고 전체를 쏟지 않는다.
- UI에서는 `<details>`/아코디언/탭으로 구현하고 펼친 상태를 기억한다.
