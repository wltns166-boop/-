# Few-Shot-Patterns — 예외 사례를 담은 예시 패턴

## 예시 구성 비율 (3–6개)
- 대표 사례 50%: 가장 흔한 입력
- 경계 사례 30%: 애매한 입력, 형식이 살짝 다른 입력
- 예외 사례 20%: 거절·"해당 없음"·정보 부족 시 올바른 반응

## 작성 규칙
- 예시마다 입력/출력을 같은 형식으로 태그로 감싼다 (`<example><input>…</input><output>…</output></example>`).
- 예시끼리 내용·길이·어조를 다양하게 해서 모델이 한 예시를 베끼지 않게 한다.
- 출력 형식은 모든 예시에서 정확히 동일해야 한다.
- 예시 순서를 바꿔도 결과가 같은지 확인한다 (마지막 예시 편향 점검).

## 절차
1. 실제 입력 데이터에서 실패하기 쉬운 유형을 먼저 모은다.
2. 유형별로 1개씩 정답 예시를 만든다.
3. 테스트 입력 10개로 돌려보고 틀린 유형의 예시를 보강한다.
