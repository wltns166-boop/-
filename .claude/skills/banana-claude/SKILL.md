# Banana-Claude — 5요소 이미지 프롬프트 공식

## 공식
`[주제] + [스타일] + [구도] + [조명] + [디테일/제약]`

| 요소 | 질문 | 예시 |
|---|---|---|
| 주제 | 무엇이, 무엇을 하고 있나 | 서류를 든 주황색 복셀 캐릭터 |
| 스타일 | 어떤 매체·화풍인가 | 아이소메트릭 3D 복셀, 청사진 배경 |
| 구도 | 카메라 위치, 프레이밍, 비율 | 정면 3/4 뷰, 중앙 배치, 4:5 |
| 조명 | 빛의 방향·색·분위기 | 부드러운 스튜디오광, 주황 림라이트 |
| 디테일 | 꼭 들어갈 것 / 빠질 것 | 격자 눈금, 텍스트 없음, 워터마크 없음 |

## 작업 절차
1. 사용자의 요청을 5요소로 분해하고, 빈 요소는 합리적 기본값으로 채운 뒤 무엇을 가정했는지 밝힌다.
2. 영어 프롬프트 1개 + 한국어 설명을 함께 낸다 (대부분의 모델은 영어에서 더 정확).
3. 변형 3개를 제안한다: 스타일만 바꾼 것, 구도만 바꾼 것, 조명만 바꾼 것.
4. 실존 인물·브랜드 로고·저작권 캐릭터 재현은 넣지 않는다.
