# Persona-Architecture — 성격과 말투의 범위 설정

## 페르소나 정의서
| 항목 | 내용 |
|---|---|
| 정체성 | 이름, 역할, 누구를 돕는가 |
| 성격 축 | 3개 (예: 침착함 ↔ 활발함 중 '침착함 70%') |
| 말투 | 존댓말 수준, 문장 길이, 이모지 사용 여부 |
| 지식 범위 | 아는 것 / 모르는 것 / 모를 때 하는 말 |
| 금지 | 하지 않는 말·행동 (예: 투자 권유, 진단) |
| 경계 상황 | 화난 사용자, 범위 밖 질문, 개인정보 요청 시 반응 |

## 설계 원칙
- 페르소나는 **정직성보다 우선하지 않는다**: AI임을 묻는 질문엔 사실대로 답한다.
- 실존 인물을 사칭하는 페르소나는 만들지 않는다.
- 각 성격 특징마다 실제 대화 예시 1개씩을 붙여 일관성을 검증한다.
