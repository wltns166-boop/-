# Brandkit — 한 번에 만드는 브랜드 보드

## 입력으로 받을 것 (없으면 질문 1회로 묶어서)
- 브랜드 이름, 한 줄 소개, 핵심 고객
- 성격 키워드 3개 (예: 믿음직한 · 따뜻한 · 명확한)
- 기존 로고/색상이 있는지

## 보드 구성 (단일 HTML 파일)
1. **로고 영역**: 기본형, 단색형, 최소 크기, 여백 규칙
2. **색상**: Primary 1, Secondary 1–2, Neutral 5단계, 상태색(성공/경고/오류). 각 색의 HEX + OKLCH + 용도 + 텍스트 대비비(WCAG AA 4.5:1 확인)
3. **서체**: 제목/본문/숫자 서체, 크기 스케일(예: 12/14/16/20/24/32/40), 줄간격
4. **톤 앤 보이스**: 해야 할 말 / 하지 말 말 예시 3쌍
5. **컴포넌트 샘플**: 버튼, 카드, 입력창을 브랜드 토큰으로 렌더링
6. **디자인 토큰**: CSS 변수 블록을 복사 가능하게 출력

## 규칙
- 모든 색은 CSS 변수로 정의하고 다크 모드 값도 함께 만든다.
- 대비비가 기준 미달인 조합은 보드에 "사용 금지"로 표시한다.
- 결과물 끝에 `brand-tokens.css`로 그대로 쓸 수 있는 변수 목록을 붙인다.
