# Chain-of-Thought — 단계별 추론 흐름 추적

## 언제 쓰나
- 계산, 여러 조건을 따지는 판단, 다단계 분석 → 사용
- 단순 조회, 형식 변환 → 불필요 (토큰 낭비)

## 프롬프트 패턴
```
<thinking> 안에서 다음 순서로 생각하세요:
1. 주어진 정보와 구해야 할 것을 정리
2. 필요한 규칙/공식 확인
3. 단계별 계산·판단
4. 결과를 원래 질문에 대입해 검증
그 다음 <answer> 안에 최종 답만 쓰세요.
```

## 추적·검증
- 각 단계가 앞 단계의 결과만 사용하는지 확인 (근거 없는 비약 표시).
- 최종 답을 거꾸로 대입해 맞는지 검증하는 단계를 반드시 둔다.
- 사용자에게는 `<answer>`만 보여주고, 추론은 디버깅·감사용으로 보관한다.
- 확장 사고(extended thinking)를 지원하는 모델이면 수동 CoT 대신 그 기능을 쓴다.
