# Template-Design — 매개변수형 중괄호 템플릿

## 형식
```
{{customer_name}}님, {{product_name}} 청구가 {{status}} 되었습니다.
{{#if amount}}지급 예정 금액: {{amount}}원{{/if}}
```

## 설계 규칙
- 변수 이름은 snake_case, 의미가 드러나게 (`{{x}}` 금지).
- 템플릿 상단에 **변수 명세표**를 둔다: 이름 / 타입 / 필수 여부 / 예시 / 기본값.
- 선택 변수는 조건 블록으로 감싸 값이 없을 때 문장이 깨지지 않게 한다.
- 한국어 조사(은/는, 이/가)는 변수 뒤에서 깨지기 쉬우므로 `{{name}}님`처럼 조사가 필요 없는 구조를 쓰거나 조사 처리 함수를 둔다.
- 사용자 입력이 프롬프트 템플릿에 들어갈 때는 구분 태그로 감싸 지시문과 섞이지 않게 한다.

## 검증
- 모든 변수를 채운 예시 1개, 선택 변수를 비운 예시 1개를 렌더링해 확인한다.
