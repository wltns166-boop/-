# Handoff-Protocols — 사람에게 전달할 문맥 파이프라인

## 이관 조건 (하나라도 해당되면 사람에게)
- 사용자가 사람을 요청
- 금전·법적·의료 판단이 필요
- 같은 문제로 2회 이상 해결 실패
- 강한 불만 또는 위험 신호

## 인계 메모 형식
```
[요약] 한 줄로 무엇이 문제인지
[고객] 이름/식별자 (필요 최소한만)
[요청] 고객이 원하는 것
[진행] 지금까지 확인·시도한 것과 결과
[미해결] 남은 문제와 막힌 이유
[감정 상태] 차분 / 불만 / 긴급
[권장 다음 행동] 담당자가 바로 할 일
```

## 규칙
- 고객이 같은 설명을 다시 하지 않아도 되게 쓴다.
- 개인정보는 업무에 필요한 범위만 포함한다.
- 고객에게는 이관 사실, 예상 대기 시간, 연결 방법을 알린다.
