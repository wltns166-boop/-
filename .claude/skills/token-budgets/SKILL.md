# Token-Budgets — 컨텍스트 윈도우 토큰 계산

## 대략 환산 (정확한 값은 해당 모델의 토큰 카운트 API 사용)
- 영어: 1토큰 ≈ 4글자 ≈ 0.75단어
- 한국어: 1글자 ≈ 1–2토큰 (영어보다 비싸다)
- 코드/JSON: 공백·기호가 많아 영어 산문보다 토큰이 많다

## 예산 배분 표 (예시)
| 항목 | 비율 |
|---|---|
| 시스템 프롬프트·지침 | 5–10% |
| 참조 문서(RAG) | 30–50% |
| 대화 기록 | 20–30% |
| 출력 여유분 | 15–25% (max_tokens) |

## 절차
1. 각 구성요소의 토큰 수를 추정(또는 측정)해 표로 만든다.
2. 합계가 한도의 80%를 넘으면 줄일 후보를 우선순위로 제시: 오래된 대화 요약 → 중복 문서 제거 → 예시 수 축소.
3. 반복 사용되는 앞부분(시스템 프롬프트, 고정 문서)은 프롬프트 캐싱 대상으로 표시한다.
