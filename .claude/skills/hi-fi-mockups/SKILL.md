# Hi-Fi Mockups — 고해상도 UI 목업

## 절차
1. 화면 목적, 주요 사용자 행동 1개, 기기(데스크톱/모바일)를 확인한다.
2. 실제 데이터처럼 보이는 콘텐츠를 쓴다 (Lorem ipsum 금지, 실제 길이의 한국어 문구·숫자).
3. 디자인 토큰(색·간격·서체)을 CSS 변수로 먼저 정의하고 그것만 사용한다.
4. 상태를 함께 그린다: 기본 / 비어 있음 / 로딩 / 오류 / 데이터 많음.
5. 하나의 HTML 파일에 여러 화면을 나란히 배치(캔버스)하고 각 화면에 라벨을 붙인다.

## 품질 기준
- 4px 간격 그리드, 텍스트 대비 AA 이상, 터치 대상 44px 이상
- 모바일 목업은 실제 375px 폭에서 가로 스크롤이 없어야 한다
- 스크린샷으로 확인 후 어긋난 정렬·잘린 텍스트를 고친다
