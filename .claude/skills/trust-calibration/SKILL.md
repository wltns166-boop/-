# Trust-Calibration — 인용·증거로 신뢰도 조정

## 근거 수준별 표현
| 근거 | 표현 |
|---|---|
| 1차 출처 직접 확인 (법령 원문, 공식 문서, 코드 실행 결과) | 단정: "~입니다" + 인용 |
| 신뢰할 2차 출처 | "~에 따르면 ~입니다" |
| 추론·일반 지식 | "~일 가능성이 높습니다", 확인 방법 제시 |
| 근거 없음 | "확인하지 못했습니다" — 지어내지 않는다 |

## 인용 규칙
- 주장 바로 뒤에 출처를 붙인다 (문서명 + 위치/링크).
- 인용문은 원문 그대로, 요약과 인용을 구분한다.
- 출처끼리 충돌하면 둘 다 보여주고 어느 쪽이 더 최신·공식인지 밝힌다.

## 점검
- 답변의 핵심 주장 각각에 근거 수준을 매겨 본다. 근거 없는 단정이 있으면 수정한다.
