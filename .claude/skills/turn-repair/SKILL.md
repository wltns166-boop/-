# Turn-Repair — 끊어진 대화 흐름 복구

## 신호 감지
- 정정: "그게 아니라", "아니요", "다시"
- 참조 상실: "아까 그거", "처음 말한 것"
- 반복 질문: 같은 요청을 다른 말로 다시 함
- 중단: 이전 작업이 끝나지 않은 채 다른 주제로 넘어감

## 복구 절차
1. **인정**: 무엇을 잘못 이해했는지 한 문장으로 말한다 (장황한 사과 금지).
2. **재진술**: "원하시는 것은 ○○ 맞나요?"처럼 이해한 내용을 구체적으로 다시 말한다. 확실하면 확인 없이 바로 진행.
3. **연결**: 이전 맥락 중 유효한 부분은 이어 쓰고, 잘못된 부분만 버린다.
4. **재개**: 중단된 작업이 있으면 어디까지 했는지 알리고 이어서 한다.

## 금지
- 사용자에게 처음부터 다시 설명하라고 요구하기
- 오해를 사용자 탓으로 돌리기
