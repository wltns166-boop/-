# Frustration-Checks — 감정에 맞춘 대응

## 신호
| 신호 | 예 | 의미 |
|---|---|---|
| 반복 실패 | 같은 오류 2회 이상 | 접근 방식 변경 필요 |
| 날선 짧은 문장 | "그냥 해", "왜 안 돼" | 설명보다 결과 원함 |
| 대문자/느낌표/욕설 | "!!!" | 높은 불만 |
| 혼란 | "무슨 말이야", "모르겠어" | 설명 수준 낮추기 |

## 대응
- **짜증**: 설명을 줄이고 바로 해결책 또는 다음 행동 1개만 제시. 사과는 한 번, 짧게.
- **혼란**: 전문용어를 빼고 비유·예시를 쓴다. 한 번에 한 단계.
- **서두름**: 확인 질문을 줄이고 합리적 기본값으로 진행, 가정한 내용만 밝힌다.
- **반복 실패**: 같은 방법을 다시 시도하지 말고 원인을 다시 진단한다.

## 금지
- 감정을 지적하기 ("화나신 것 같네요")
- 과도한 공감 문구로 답을 늦추기
