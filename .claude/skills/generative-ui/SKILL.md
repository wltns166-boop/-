# Generative-UI — 반응형 위젯 렌더링

## 응답 형태 선택 기준
| 응답 내용 | 위젯 |
|---|---|
| 비교 3개 이상 | 표 |
| 시간에 따른 변화 | 차트 |
| 사용자가 값을 골라야 함 | 버튼 칩 / 선택 폼 |
| 단일 객체 요약 | 카드 |
| 단계 진행 | 체크리스트 / 스테퍼 |
| 그 외 | 일반 텍스트 |

## 설계 규칙
- 모델은 UI 코드를 직접 만들지 않고 **스키마(JSON)** 를 낸다: `{ "type": "table", "props": {...} }`
- 프론트엔드는 허용 목록(whitelist)에 있는 컴포넌트만 렌더링하고, 알 수 없는 type은 텍스트로 대체한다.
- 모든 위젯은 텍스트 대체(fallback)와 접근성 라벨을 가진다.
- 위젯 안의 동작(버튼 클릭)은 다음 사용자 메시지로 변환해 대화 흐름에 남긴다.
