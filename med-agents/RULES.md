# 병력정리 개편 — 확정 규칙 (사용자 결정 기록)

> 새 세션에서 이 작업을 이어갈 때 반드시 먼저 읽을 것.
> 원칙: **AI는 표를 그대로 JSON으로 옮기기만(계산 금지), 중복 제거·합산·판정은 전부 코드가 한다.**

## 처방조제 (에이전트 2) — 2026-07-09 확정

1. **중복 처리**: 같은 진료시작일 + 같은 기관(병·의원/약국)은 중복 입력이어도 1회 방문으로 합침.
2. **방문 대표 일수**: 총투약일수 칸 값 그대로 반영. 같은 방문에 약별 일수가 다르면(주사 1일 + 내복약 7일) **가장 긴 일수**를 대표값으로. ← 사용자 확정
3. **30일 이상 복용 판정**: 기록된 약 처방 총일수 **그대로만** 본다.
   병원·약국 짝 맞추기 없음, 방문 간 합산 없음. 어떤 방문이든 대표 일수 ≥ 30일이면 해당. ← 사용자 확정
4. 출력 형식: `2026년1월19일 / 봉명피보약국 / 약처방 : 7일`
   (병원과 약국이 같은 처방이어도 각각 한 줄씩 표시)
