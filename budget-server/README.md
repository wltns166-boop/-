# 우리집 가계부 — 컴퓨터 2대 실시간 동기화

`household-budget.html` 가계부를 여러 컴퓨터에서 **같은 데이터로** 쓰게 해주는
개인용 동기화 서버입니다. 보험 인트라넷 서버(`server/`)와는 완전히 별개이며,
포트도 다릅니다(가계부: **4001**).

```
┌──────────────┐        ┌───────────────────────┐
│  컴퓨터 1      │◀──────▶│   가계부 서버            │
│  (서버 겸용)   │  HTTP  │  (Node + Express)      │
├──────────────┤  /api  │  - 비밀번호 잠금          │
│  컴퓨터 2      │◀──────▶│  - 공유 데이터 저장소      │
└──────────────┘        │  - 가계부 화면 서빙        │
                        └───────────────────────┘
                                │
                    budget-server/data/db.json
```

- 한쪽에서 거래를 저장하면 즉시 서버로 올라가고, 다른 컴퓨터는 **3초마다**
  변경을 감지해 자동으로 화면을 갱신합니다.
- 서버가 꺼져 있거나 연결이 끊기면 각 컴퓨터에서 오프라인으로 계속 쓸 수 있고,
  화면 상단 배지가 `🔴 연결 끊김`으로 바뀌었다가 복구되면 자동 재동기화됩니다.

---

## 실행 방법

### 1) 서버 켜기 (두 컴퓨터 중 한 대에서)

[Node.js](https://nodejs.org)가 설치되어 있어야 합니다.

```bash
cd budget-server
npm install                      # 최초 1회만
PASSWORD=원하는비밀번호 JWT_SECRET=아무긴문자열 npm start
```

Windows(cmd)라면:

```bat
cd budget-server
npm install
set PASSWORD=원하는비밀번호 && set JWT_SECRET=아무긴문자열 && npm start
```

실행되면 이렇게 표시됩니다:

```
우리집 가계부 서버 실행 중
 ─ 이 컴퓨터:  http://localhost:4001
 ─ 다른 컴퓨터: http://<이 컴퓨터의 IP>:4001
```

> - `PASSWORD` 미지정 시 기본값은 `budget1234`입니다. 꼭 바꿔 쓰세요.
> - `JWT_SECRET`을 지정하지 않으면 서버를 재시작할 때마다
>   각 컴퓨터에서 비밀번호를 다시 입력해야 합니다.

### 2) 서버를 켠 컴퓨터에서 접속

브라우저에서 **http://localhost:4001** → 비밀번호 입력.
상단에 `🟢 동기화 중` 배지가 보이면 성공입니다.

### 3) 다른 컴퓨터에서 접속 (같은 와이파이/네트워크)

1. 서버 컴퓨터의 내부 IP를 확인합니다.
   - Windows: `ipconfig` → "IPv4 주소" (예: `192.168.0.10`)
   - Mac/Linux: `ifconfig` 또는 `ip addr`
2. 다른 컴퓨터 브라우저에서 **http://<서버 IP>:4001** 접속 (예: `http://192.168.0.10:4001`)
3. 같은 비밀번호로 들어가면 **같은 가계부**가 보입니다.
   한쪽에서 거래를 추가하면 다른 쪽에 3초 안에 나타납니다.

> 서버 컴퓨터의 방화벽이 4001 포트를 막으면 접속이 안 됩니다. 해당 포트를 허용하세요.

### 처음 연결할 때 기존 데이터는?

이미 `household-budget.html`을 파일로 열어 쓰던 기록이 있다면,
**그 브라우저로 서버에 처음 접속하는 순간** 로컬 기록이 자동으로 서버에 올라가
두 컴퓨터가 이어서 쓸 수 있습니다. (서버가 비어 있을 때만 올라갑니다.)

## 환경변수 정리

| 변수 | 설명 | 기본값 |
|------|------|--------|
| `PASSWORD` | 접속 비밀번호 | `budget1234` (변경 권장) |
| `JWT_SECRET` | 로그인 토큰 서명 키. 지정해야 재시작 후에도 로그인 유지 | 임시 키 |
| `PORT` | 서버 포트 | `4001` |
| `DATA_DIR` | 데이터(`db.json`) 저장 폴더 | `budget-server/data` |

## API 요약

| 메서드 | 경로 | 설명 |
|--------|------|------|
| POST | `/api/login` | 비밀번호 확인 → `{ token }` |
| GET  | `/api/state` | 전체 가계부 데이터 조회 |
| GET  | `/api/state/version` | 변경 감지용 버전(폴링) |
| PUT  | `/api/state/:key` | 한 항목 저장 (`tx`, `budgets`, `recurring`, `cats`) |
| PUT  | `/api/state` | 여러 항목 일괄 저장 |
| GET  | `/api/health` | 서버 상태 확인 (인증 불필요) |

`/api/state` 계열은 모두 `Authorization: Bearer <token>` 헤더가 필요합니다.

## 집 밖에서도 쓰고 싶다면 (선택)

보험 인트라넷과 같은 방식으로 클라우드(Render, Railway 등)에 올리면
HTTPS 주소 하나로 어디서든 접속할 수 있습니다. 배포 서비스에서
시작 명령을 `cd budget-server && npm install && npm start`로 지정하고
`PASSWORD`, `JWT_SECRET`, `DATA_DIR`(영속 디스크 경로) 환경변수를 설정하세요.
