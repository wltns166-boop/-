# 집 PC에서 매일 경매 보고서 받기 (Claude 데스크톱 앱 "로컬 루틴")

클라우드에서 돌리면 법원경매정보(courtauction.go.kr)가 해외 IP라 막힙니다.
집 PC(한국 인터넷)에서 돌리면 법원경매정보를 직접 볼 수 있습니다.

---

## 0. 준비물

- Claude **유료 요금제** (Pro / Max / Team / Enterprise) — 무료 요금제는 예약 작업이 안 됩니다
- 매일 아침 **켜져 있는 PC** (Windows 또는 Mac)
- 이 폴더(`경매보고서`)를 PC에 받아두기
  - GitHub에서 저장소를 내려받거나, `로컬작업_지시문.md` 파일 내용만 복사해도 됩니다

---

## 1. Claude 데스크톱 앱 설치

1. https://claude.ai/download 에서 PC용 앱을 설치합니다.
2. 앱을 열고 지금 쓰는 계정으로 로그인합니다.

## 2. 보고서 저장 폴더 만들기

- 예: `문서\경매보고서` (Windows) 또는 `문서/경매보고서` (Mac)
- 매일 보고서 PDF가 이 폴더 안 `reports` 폴더에 쌓입니다.

## 3. 로컬 루틴 만들기

1. 앱 위쪽에서 **Code** 탭을 누릅니다.
2. 왼쪽 메뉴에서 **Routines**를 누릅니다. 안 보이면 **More** 안에 있습니다.
3. **New routine** → **Local**을 고릅니다. **Cloud**를 고르면 안 됩니다.
4. 아래처럼 채웁니다.

| 칸 | 입력할 내용 |
|---|---|
| Name | 부동산 경매 일일 보고서 (집 PC) |
| Instructions | `로컬작업_지시문.md` 파일 내용을 **전부 복사해서 붙여넣기** |
| Schedule | Daily, 오전 7:15 |
| Working folder | 2번에서 만든 `경매보고서` 폴더 (처음에 "신뢰(Trust)"를 눌러야 합니다) |
| Permission mode | 자동 승인 모드를 고르세요 (웹 조회·파일 저장을 매번 묻지 않도록) |

5. 저장합니다.

## 4. 바로 테스트

- 만든 루틴을 열고 **Run now**(지금 실행)를 누릅니다.
- 20~30분 뒤 `reports` 폴더에 `경매보고서_날짜.pdf`가 생기면 성공입니다.
- 보고서 첫 줄에 **"법원경매정보 접속: 성공/실패"**가 적힙니다. 여기서 집 인터넷으로 되는지 확인할 수 있습니다.

## 5. 꼭 지켜야 할 것

- **PC가 켜져 있고 절전(잠자기) 상태가 아니어야** 합니다. 노트북 덮개를 닫으면 잠자기가 되어 실행되지 않습니다.
- **Claude 앱이 켜져 있어야** 합니다. 최소화는 괜찮고, 완전히 종료하면 실행되지 않습니다.
- 앱 **설정 → Desktop app → General → Keep computer awake**를 켜 두세요.
- 아침에 PC가 꺼져 있어서 못 돌았으면, 켰을 때 밀린 1회분을 자동으로 실행합니다.

## 6. 클라우드 보고서와 중복

- 지금 클라우드에서도 매일 7:17에 보고서가 돌고 있습니다.
- 집 PC 루틴이 잘 되는 걸 확인하면 클라우드 쪽은 꺼 달라고 말씀해 주세요. 그 전까지는 백업으로 두면 됩니다.

## 7. 옥션원은?

- 로그인 정보를 자동 작업에 넣는 것은 **권하지 않습니다**. 계정 정지 위험이 있고 이용약관에도 어긋날 수 있습니다.
- 옥션원에서 본 관심 물건은 `관심물건.txt`에 사건번호를 한 줄씩 적어 두세요. 예: `2026타경12345 청주지방법원`
- 보고서가 그 물건들을 우선 분석합니다.
