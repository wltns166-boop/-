쇼츠 자동 업로드

개인이 만든 영상을 본인의 YouTube 채널에 자동으로 올려주는 개인용 도구입니다.

무엇을 하는 도구인가요

내 PC의 지정된 폴더를 감시하다가 새 영상 파일이 들어오면, YouTube Data API를 통해 내 채널에 업로드합니다. 파일 이름이 영상 제목이 되고, 업로드가 끝난 파일은 완료 폴더로 옮겨집니다.

누가 쓰나요

제작자 본인만 사용합니다. 회원가입이나 타인의 계정 연결 기능은 없습니다.

어디서 실행되나요

서버를 따로 두지 않고, 사용자의 개인 PC에서만 실행됩니다. 인증 정보와 영상 파일은 모두 그 PC 안에만 저장됩니다.
