서비스 약관

최종 수정일: 2026년 9월 22일

1. 목적

본 약관은 개인용 도구 “쇼츠 자동 업로드”(이하 “본 도구”)의 이용 조건을 정합니다. 본 도구는 제작자 본인이 자신의 YouTube 채널 운영을 위해 만든 비상업적 개인용 프로그램입니다.

2. 이용 범위

본 도구는 사용자 본인 소유의 YouTube 채널에, 본인이 업로드 권한을 가진 영상을 올리는 용도로만 사용됩니다. 타인의 저작물을 무단으로 업로드하는 데 사용해서는 안 됩니다.

3. YouTube 약관 준수

본 도구를 사용하는 것은 YouTube 서비스 약관에 동의하는 것을 포함합니다. 본 도구는 YouTube Data API 서비스를 이용하며, 관련 정책을 준수합니다.

4. 보증의 부인

본 도구는 있는 그대로 제공되며, 업로드의 성공이나 지속적인 동작을 보증하지 않습니다. API 할당량 초과, 네트워크 오류, 정책 변경 등으로 업로드가 실패할 수 있습니다.

5. 책임의 제한

본 도구의 사용으로 발생하는 결과에 대한 책임은 사용자에게 있습니다. 업로드되는 콘텐츠의 적법성과 저작권 확보 역시 사용자의 책임입니다.

6. 약관의 변경

본 약관은 사전 고지 없이 변경될 수 있으며, 변경된 내용은 이 페이지에 게시된 시점부터 적용됩니다.
