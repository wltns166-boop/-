개인정보처리방침

최종 수정일: 2026년 9월 22일

이 방침은 개인용 도구 “쇼츠 자동 업로드”(이하 “본 도구”)에 적용됩니다. 본 도구는 제작자 본인이 자신의 YouTube 채널에 영상을 올리기 위해 만든 것으로, 사용자의 개인 PC에서만 실행됩니다.

1. 수집하는 정보

본 도구는 이름, 이메일 주소, 연락처 등 개인을 식별하는 정보를 수집하지 않습니다. 사용자가 Google 계정으로 로그인하여 권한을 허용하면, 다음 정보만 사용자의 PC에 저장됩니다.

  • YouTube 업로드 권한을 나타내는 인증 토큰 (액세스 토큰 및 갱신 토큰)
  • 업로드한 영상의 파일명, 영상 ID, 업로드 시각

2. 사용하는 권한

본 도구는 Google OAuth 2.0을 통해 https://www.googleapis.com/auth/youtube.upload 권한 하나만 요청합니다. 이 권한은 사용자의 채널에 영상을 업로드하는 데에만 쓰이며, 영상 조회·수정·삭제나 채널 정보 열람에는 사용되지 않습니다.

3. 정보의 보관

모든 정보는 사용자의 개인 PC 내부에만 저장됩니다. 본 도구는 별도의 서버나 데이터베이스를 운영하지 않으며, 수집한 정보를 외부로 전송하지 않습니다.

4. 제3자 제공

본 도구는 어떠한 정보도 제3자에게 판매, 대여, 제공하지 않습니다. 영상 업로드를 위한 Google(YouTube) API 통신 외에 외부와 주고받는 데이터는 없습니다.

5. 정보의 삭제 및 권한 철회

저장된 인증 토큰은 PC의 해당 파일을 삭제하면 즉시 제거됩니다. Google 계정에서 본 도구의 접근 권한을 철회하려면 Google 계정 권한 설정에서 해당 앱을 삭제하면 됩니다.

6. Google API 서비스 이용자 데이터 정책

본 도구의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요구사항 포함)를 준수합니다. 또한 본 도구는 YouTube 서비스 약관을 따릅니다.

7. 문의

본 방침에 관한 문의는 Google OAuth 동의 화면에 표시된 지원 이메일 주소로 보내주시기 바랍니다.
